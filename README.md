# CSC584-Individual-Assignment-1

## Project Description
A simple web application that collects personal profile information through an HTML form, sends it to a Java Servlet using HTTP POST, and displays it on a JSP page.

Data flow: HTML Form -> Servlet (POST) -> JSP

## Technologies Used
- HTML5
- CSS3
- Java Servlet (Java EE 7, javax.servlet)
- JavaServer Pages (JSP)
- JDK 1.8
- GlassFish Server 4.1.1
- NetBeans IDE 8

## How to Run
1. Install JDK 8 and NetBeans 8 (with Java EE / GlassFish support).
2. Clone or download this repository.
3. Open NetBeans, choose File > Open Project, and select the project folder.
4. Make sure GlassFish Server 4.1.1 is attached (Project Properties > Run).
5. Right-click the project, choose Clean and Build, then Run.
6. The browser opens the form. Fill it in and click Submit Profile.
